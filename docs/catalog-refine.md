# Catalog Refine (archived)

The unfinished feature is retained under [`_archive/catalog-refine/`](../_archive/catalog-refine/README.md). Its configuration, helper, runtime, empty-state CSS, renderer snapshot, and behavior notes are no longer connected to the public generator.

All public catalogs render every collection product in descending numeric `sequence` (latest first), with no Refine controls or script. A normal rebuild or push cannot enable the archived feature. Shared dropdown components remain available to active interfaces.

See [`_archive/README.md`](../_archive/README.md) for GitHub Pages exclusion and validation instructions. Restoring the feature requires explicit source changes; the previous `publicEnabled` switch exists only in the archived snapshot.
